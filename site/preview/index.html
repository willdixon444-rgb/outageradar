How to read this board

Official status is what each provider publishes on its own status page. Each service name links there.

Our check is OutageRadar asking the provider’s server or website for a reply every five minutes. A reply proves the server is up; it does not prove the AI is answering questions.

Up (our check only) is used where a provider publishes no status feed, so our check is the only signal. It is shown with a dashed outline so it is never mistaken for an official all-clear.

All times are UTC. When we cannot get fresh data, services show Unknown rather than a guess.
