If GitHub Copilot is down

GitHub Copilot is used through its own apps and editor extensions, so there is no drop-in replacement you can switch to by changing an address and a key. Follow the official status page for updates; the history above shows how long past incidents lasted.

How OutageRadar checks GitHub Copilot

Official status: GitHub publishes Copilot’s status on githubstatus.com. OutageRadar reads its Copilot and Copilot AI Model Providers components every five minutes.

Our check is OutageRadar asking GitHub Copilot’s API server for a reply at the same time. A reply, even “needs a key”, proves the server is up; it does not prove the AI is answering questions. The time shown is how long the API server took to answer our check, from Cloudflare’s network; it varies by moment and location and is not the speed of AI replies.

An incident is logged when the official status shows degraded performance or an outage, or when our check fails twice in a row. It ends after two healthy checks in a row. Times are when our checker saw the change, within five minutes.
