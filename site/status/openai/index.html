If ChatGPT is down: switch to a backup

These AI APIs work with the official OpenAI library. Change the address and the key, pick a model from that provider’s list, and you’re running again. Each shows its live status, so you don’t switch to one that’s also down.

  • OpenRouter Checking…

    One key for many companies' models. Pick a model from a different company than the one that is down.

    OpenRouter’s current model list · setup guide

    Python

    import os
from openai import OpenAI

client = OpenAI(
    base_url="https://openrouter.ai/api/v1",
    api_key=os.environ["OPENROUTER_API_KEY"],
)
reply = client.chat.completions.create(
    model="PICK_FROM_LIST",  # see OpenRouter's current model list
    messages=[{"role": "user", "content": "Hello"}],
)
print(reply.choices[0].message.content)

    JavaScript

    import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://openrouter.ai/api/v1",
  apiKey: process.env.OPENROUTER_API_KEY,
});
const reply = await client.chat.completions.create({
  model: "PICK_FROM_LIST", // see OpenRouter's current model list
  messages: [{ role: "user", content: "Hello" }],
});
console.log(reply.choices[0].message.content);

How OutageRadar checks ChatGPT / OpenAI

Official status is what ChatGPT / OpenAI publishes on its own status page, read every five minutes.

Our check is OutageRadar asking ChatGPT / OpenAI’s API server for a reply at the same time. A reply, even “needs a key”, proves the server is up; it does not prove the AI is answering questions. The time shown is how long the API server took to answer our check, from Cloudflare’s network; it varies by moment and location and is not the speed of AI replies.

An incident is logged when the official status shows degraded performance or an outage, or when our check fails twice in a row. It ends after two healthy checks in a row. Times are when our checker saw the change, within five minutes.

Common ChatGPT API errors

  • OpenAI API error 503: server_is_overloaded
  • OpenAI API error 429: rate limit reached or slow_down
  • OpenAI API: You exceeded your current quota (insufficient_quota)
