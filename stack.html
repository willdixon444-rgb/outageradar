My stack

The tools I use to build, host and monitor my trading bots. I’m not a professional coder, so everything here has to work for someone learning as they go.

Claude

AI coding assistant

What I use it for
Writing and debugging all of the code behind my bots. I describe what I want, review what comes back, and iterate.
My take
This is the reason I can build bots at all. I explain what I want in plain English and get working code back, along with an explanation of what it does. The catch is that AI can be confidently wrong, so I make it diagnose a problem and explain its plan before it writes any code, and I test everything on paper before it touches real money. If you’re willing to test carefully, it’s the best starting point for a non-coder.
Visit Claude

GitHub

Code storage and version history

What I use it for
Keeping every version of every bot so I can roll back when something breaks.
My take
Every bot lives in its own repo, and that history has saved me more than once after a bad change. The terminology (commits, branches, pushes) takes some getting used to, but you can start by uploading files through the website and learn the rest as you go. Essential for anyone building anything.
Visit GitHub

Render

Hosting

What I use it for
Running my bots and web apps around the clock without managing a server myself.
My take
Connect a GitHub repo and Render redeploys every time you push a change, which is about as simple as hosting gets. The dashboard, logs and settings take a little learning, and it’s worth keeping an eye on which services are free and which are paid. A good fit if you want your bot running 24/7 without becoming a server admin.
Visit Render

Supabase

Database

What I use it for
Storing trades, signals and logs in a PostgreSQL database my bots read and write.
My take
Its web dashboard lets me look at my bots’ data in tables without writing code, which makes checking what a bot actually did much easier. Databases have a learning curve, and planning your tables before you start saves headaches later. Worth it as soon as your bot needs to remember anything between runs.
Visit Supabase

Discord

Alerts

What I use it for
Sending my bots’ alerts and status updates to my phone in real time.
My take
I run a private server where my bots post updates, so my phone tells me what’s happening wherever I am. Setting up a webhook is free and simple. The trick is deciding what deserves an alert, because a noisy bot gets ignored fast. Great for anyone who wants free, real-time notifications.
Visit Discord

Python and Flask

Programming language and web framework

What I use it for
The language and framework my bots are written in. Free and open source.
My take
Python has a library for almost everything in trading, and AI assistants write it well, which matters when you’re not a coder. Flask handles the small web pieces, like status pages and endpoints. The most common headaches are package versions that work on my machine but not on the server. A safe default for your first bot.
